Detalhes do pedido

Novo pixel

Eventos Manager → Fontes de dados. É um número de 15 a 16 dígitos.

Eventos Manager → Configurações → Gerar token de acesso. Sem ele a nota do evento não passa de 6 a 7, porque e-mail e telefone só existem no servidor.

Em Eventos de teste, no Events Manager. Com ele os eventos aparecem lá sem contaminar os dados reais. Deixe vazio quando for para produção.

Código para a landing page

Cole antes de </head> na sua página de vendas, no lugar do pixel do Meta. Ele inicializa o pixel, dispara o PageView e — o que o pixel puro não faz — leva os identificadores do clique até o checkout, que está em outro domínio.
